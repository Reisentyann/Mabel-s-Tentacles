## 维护约定

长期设计和接口约定放在 `docs/`，开发交接统一放在 `docs/change/`。交接文档应注明记录日期、验证状态和下一步；历史记录不代表当前实现。重复内容保留为明确标识的历史副本，接手任务只维护一个入口。

文档链接相对当前文档定位；代码路径默认相对仓库根。移动文档时同步更新引用。代码、测试与旧交接冲突时，先检查当前实现，再修正文档。
