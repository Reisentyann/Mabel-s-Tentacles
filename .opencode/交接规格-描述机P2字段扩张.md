### 2.1 fingerprint.go 收尾（把半成品补完）

**A. `countFP` 行长统计块**（现有"行遍历：行长统计"段落）改为同时记录最长行与有效行数：

```go
	// —— 行遍历：行长统计 ——
	// 末尾空段是文件以 \n 结尾时 Split 的伪影，不是真实行，跳过。
	if len(c.lines) > 0 {
		var sum, sumSq float64
		n := 0
		for i, raw := range c.lines {
			l := strings.TrimRight(raw, "\r")
			if i == len(c.lines)-1 && strings.TrimSpace(l) == "" {
				continue
			}
			w := len([]rune(l))
			if w > fp.longestLine {
				fp.longestLine = w
			}
			sum += float64(w)
			sumSq += float64(w) * float64(w)
			n++
		}
		fp.effLines = n
		if n > 0 {
			mean := sum / float64(n)
			fp.avgLineLen = describer.Round2(mean)
			fp.lineLenStd = describer.Round2(math.Sqrt(math.Max(0, sumSq/float64(n)-mean*mean)))
		}
	}
```

**B. 在 `countFP` 的"时间戳"段落之后**（`fp.tsSpan` 赋值块之后）加时间戳行占比：

```go
	// —— 时间戳行占比（日志规整度指纹）——
	tsLines := 0
	for _, raw := range c.lines {
		if reTsLine.MatchString(strings.TrimRight(raw, "\r")) {
			tsLines++
		}
	}
	if fp.effLines > 0 {
		fp.tsLineOK = true
		fp.tsLineRatio = describer.Round2(float64(tsLines) / float64(fp.effLines))
	}
```

**C. 文件末尾追加 4 个新 extractor**（风格仿照现有函数）：

```go
func extractLongestLine(ctx *textCtx) any { return ctx.FP().longestLine }

// extractMinified 压缩单行文件判定：有效行数 ≤3 且最长行 >500 rune
// （minified js/json / data URI dump；纯计数口径，确定性）。
func extractMinified(ctx *textCtx) any {
	fp := ctx.FP()
	return fp.effLines > 0 && fp.effLines <= 3 && fp.longestLine > 500
}

func extractTimestampLineRatio(ctx *textCtx) any {
	fp := ctx.FP()
	if !fp.tsLineOK {
		return nil
	}
	return fp.tsLineRatio
}

// extractBracketBalance 括号配平率：Σmin(开,闭)/Σ(开+闭)×2，全配平=1；
// 无任何括号不产键（1.0 与"无括号"不可区分时宁可缺失）。
func extractBracketBalance(ctx *textCtx) any {
	fp := ctx.FP()
	if !fp.bracketOK {
		return nil
	}
	return fp.bracketBal
}
```

| 键 | 类型 | 算法口径 |
|---|---|---|
| `cod-image-color-count` | int | 像素 RGB 量化到 4bit/通道（`r>>4,g>>4,b>>4` 组 key）计唯一色数（0-4096） |
| `cod-image-flat-ratio` | number | 覆盖 ≥5% 像素的量化色桶（同上 4bit 量化）的像素占比之和，Round2。>0.9 ≈ 扁平插画/图标 |
| `cod-image-dark` | bool | `brightness < 25`（复用已算的 mean luma） |
| `cod-image-light` | bool | `brightness > 80` |
| `cod-image-saturation` | number | 平均饱和度 ×100（现有 `avgSat` Round1 后 ×100） |
| `cod-image-warm-ratio` | number | H∈[0,60]∪[330,360] 的像素占比，Round2 |
| `cod-image-cool-ratio` | number | H∈[180,300] 的像素占比，Round2 |
| `cod-image-edge-density` | number | Sobel 幅值 >40 的像素占比（采样网格内部点，跳过边界），Round2。线稿/文字截图高 |
| `cod-image-sharpness` | number | 拉普拉斯响应方差（采样网格内部点），Round1。模糊图低 |
| `cod-image-symmetry` | number | 水平翻转像素对 luma 差 <16 的配对占比，Round2。海报/封面构图高 |
| `cod-image-alpha-ratio` | number | `a < 250` 的像素占比，Round2；无透明通道产 0 |
| `cod-image-skin-tone-ratio` | number | 肤色范围像素占比：R>60 且 R>G>B 且 R-B>15 且 \|R-G\|<80，Round2。人像/插画人物检测 |
| `cod-image-entropy` | number | 像素 luma 直方图（32 桶）香农熵，Round2。纯色图≈0，噪点图高 |

实现要点：
- 在现有 `// 亮度 / 对比度` 计算后插入这些统计，尽量并入同一趟 `for _, p := range px` 循环；Sobel/拉普拉斯/对称需要二维坐标——`sample` 返回的是一维切片，**改造 `sample` 同时返回 `width, height int`**（采样后网格宽高），调用处 `px, gw, gh := sample(img, 128)`，梯度类字段在网格上用 `px[y*gw+x]` 访问。
- Sobel 幅值简化为 `|gx|+|gy|`（曼哈顿），阈值 40。
- 拉普拉斯核 `4*c - l - r - t - b`，收集全部内部点响应值后算方差。
- `warm-ratio`/`cool-ratio`/`skin-tone-ratio`/`saturation` 复用 `rgbToHSL(p)`。
- GIF 多帧只分析首帧（现有行为，保持不变）。

### 2.5 indexer Stats()（`indexer-go/`）

`indexer.go` 接口加方法 + 类型：

```go
// Stats 索引机运行计量（自省接口）：排查"索引与 DB 不一致"时的抓手。
type Stats struct {
	Fields   int `json:"fields"`   // 桶数（被索引的字段数）
	Keys     int `json:"keys"`     // 全部桶的键总数（enum/multi 的值键数 + num 的条目数）
	Mounts   int `json:"mounts"`   // 挂载点总数（uuid×值 关联数）
}

// Indexer 接口加：
	// Stats 返回运行计量。纯读操作。
	Stats() Stats
```

`bucket` 接口加 `stats() (keys, mounts int)`：
- enumBucket/multiBucket：keys=len(m)，mounts=Σlen(set)
- numBucket：keys=len(distinct val) 可简化为 len(sorted)，mounts=len(sorted)。**简化：两者都返回 len(sorted)，注释注明 num 桶 keys 按条目计**

`mem.go` 实现：读锁，遍历 buckets 累加。

`mem_test.go` 加测试：Rebuild 几个字段后断言 Stats 数值；Update 后 mounts 变化正确。
