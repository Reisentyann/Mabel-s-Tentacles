## 简介

这是一个用 Go 开发的 MCP 服务器项目，用于管理、创造、分类文件。聊天机器人风靡全球，铃仙意识到让机器人来管理文件是非常有必要的。但传统 agent 直接管理文件，面临着易出错、没有固定流程、文件一多就找不到的风险。

基于此，我制作了一个面向 agent 的 MCP 文件管理器：agent 就好好聊天，文件方面的事情就交给纯粹的理性分析吧。

**特色：** 这个项目与其他项目不同的是，它正在开发一个相当特殊的文件描述机，我配置了大量描述字段，比如这个文件有多少字符，文件中的标题有哪些，有多少表格，英文很多吗，最长的一句话有多长……
设计意图是，尽可能完整的描述这个文件，并且想办法设计量化标准，以便于agent可以模糊查询某些文件。
对此，描述机，索引机，管理机是必要的。

至于为什么选 Go——因为 Go 的体感相当优雅。

技术栈：Go（单体后端，同进程提供 MCP 与 HTTP API）· Vue 3 · PostgreSQL · Docker Compose。

## 功能

**MCP 工具**（agent 调用）：

| 工具 | 功能 |
|---|---|
| `write_file` / `upload_file` | 新建文本文件，或上传图片/二进制文件（重名拒绝，写完自动分析，回执带文件编号和 24h 极简下载短链） |
| `read_file` | 读文件（可按路径或文件编号 UUID 读，常读的小文件走内存缓存） |
| `modify_file` / `patch_file` | 改文件：追加/覆写，或者用 `patch_file` 找准上下文做局部精准替换，不用整篇重写 |
| `move_file` / `copy_file` | 移动/重命名（编号、描述、归属都不变）/ 复制文件（连描述一起搬，并记一笔"复制自哪"） |
| `create_directory` / `list_directory` | 建文件夹、按目录编号列出/新建子目录和文件 |
| `delete_file` | 软删除：放进回收站，保留描述和来龙去脉，防误删 |
| `stat_file` / `get_file_info` | 查单个文件的状态，或直接拿齐 90 多个量化描述字段 |
| `list_files` | 分页列出文件，可按关键词过滤，标出哪些还没写描述 |
| `list_index_fields` | 拿一张"能按什么条件查文件"的字段目录：每个字段啥意思、现在有哪些值、多大算"大" |
| `search_files` | 按字段条件找文件（等于 / 大于小于 / 区间 / 包含 / 有没有），支持"且 / 或 / 非"自由组合 |
| `describe_file` / `analyze_file` | 给文件写人工描述和标签（机器算的字段不许改）/ 让系统把文件重读一遍刷新字段 |
| `audit_files` | 管理员盘库对账：看看有没有盘上有但库里没记的孤儿文件、或者反过来的幽灵记录 |
| `execute_command` / `get_command_history` | 执行 Shell 命令（60s 超时）/ 查历史执行结果 |
| `mabel_quote` | 让梅贝尔说随机台词（1–5 段，附带语气指导，方便 agent 沉浸式陪聊） |
| `pseudo_random` / `true_random` | 伪随机机（快、本地娱乐用）/ 真随机机（连物理世界量子源，取不到就报错，绝不拿伪随机凑数） |
| `jm_comic` | 查或下载 JMComic 本子，自动打包成 ZIP 存进文件库，并生成下载短链 |

另外还配了 **Resources**（字段目录 `mabel://catalog/fields`、搜索指南 `mabel://guide/search-contract`、梅贝尔人设 `mabel://persona/system`）和 **Prompts**（整理工作区、给漏网文件补描述、搜索向导、梅贝尔对话模版），方便 agent 自己看说明书干活。

**文件存在哪**：agent 只管用顺手的路径（比如 `小说/第一章.txt`），文件在磁盘上的实际位置由系统随机分配——盘面上全是随机文件名，看不出任何文件是什么、在哪。就算有人摸到了服务器磁盘，也猜不到文件放哪。

**多用户**：每个用户有自己独立的空间，你写你的 `笔记.txt`、我写我的 `笔记.txt`，互不干扰。要读别人公开的文件，加个前缀 `~用户名/文件名` 就行；别人标了私密的文件，除了主人和管家谁都动不了。文件默认公开，谁都能用。

**Web 前端**（人类使用，深色书房风格管理台）：

| 功能 | 说明 |
|---|---|
| 文件树与多选 | 左侧目录树导航；支持多选、批量软删除与批量打包下载为 ZIP |
| 在线预览与就地编辑 | 图片直接看缩略/大图，文本代码支持在线预览；列表里直接改描述和标签 |
| 极简短链分享 | 一键生成 24 小时有效的短链（`/d/{code}`），直接丢给朋友就能下载，中文名不乱码 |
| 详情与来龙去脉 | 看机器算出来的全部 90+ 个字段，以及复制自哪、移动自哪的完整记录 |
| Agent 调用看板 | 独立 `/operations` 页面，实时看 agent 调了什么工具、传了什么参数 |

**已经做好的**：

| 功能 | 说明 |
|---|---|
| 文件描述引擎 | 自动读文件内容，产出 90 多个量化字段：语言、行数、表格数、最长句、英文占比、是代码还是文档、图片色调…纯计算，不需要 AI 参与，结果永远一致 |
| 字段查询 | 这些字段全部能当搜索条件——"找中文的、带表格的、100 行以上的文件"直接查；条件还能叠"且 / 或 / 非" |
| 读写排队不打架 | 同一个文件的写入、修改和后台巡检会自动排队，任务记在数据库里，就算中途重启也会接着干完，不会把记录搞乱 |
| 重名保护与自动巡检 | 新建遇到同名文件直接拦住不覆盖；哪怕文件被绕过系统直接改了，后台巡检也会发现并重新分析 |
| 混沌机 | 第四个独立模块：梅贝尔台词机、真/伪随机机、JMComic 下载入库 |

**还没做的**：

| 功能 | 说明 |
|---|---|
| 语义描述 | 现在只有机器算的事实字段，"这文件讲了什么"这种理解性描述还没接 AI |
| 对话标识 | QQ 里谁让 agent 存的文件，就自动归到谁名下（现在归统一的管家空间） |
| 谱系图 | 来龙去脉数据已经有了，画成图还没做 |
| 游戏室 | 路径分区留好了（`game/` 开头的自动归档），玩法还没做 |

还有更多的功能。

## 快速开始

### 1. 服务器部署（Docker Compose）

```bash
cp .env.production.example .env
# 编辑 .env：把数据库密码、JWT_SECRET、ADMIN_PASSWORD 换成自己的；
# 填好 DOWNLOAD_BASE_URL=https://你的域名（这样生成的短链才能直接在外网点开下载）

docker compose up -d --build
```

- **AstrBot 接入**：如果 AstrBot 也跑在同一台服务器的 Docker 里，把它加进 `mabel-s-tentacles_default` 网络，MCP 地址直接填 `http://agent_backend:8080/sse` 即可；宿主机直连填 `http://127.0.0.1:18001/sse`。
- **反向代理**：前端在 `18080` 端口；如果用 1Panel 反代挂域名，记得把 `/d/` 路径单独转给后端的 `18001` 端口，短链下载才通。

### 2. 本地开发（Windows / PowerShell 7）

```powershell
# 1. 先把数据库拉起来
docker compose up -d postgres

# 2. 一键编译后端(8080) + 启动前端 dev(5173)
./start-dev.ps1
```
